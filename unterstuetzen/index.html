Ein Community-Projekt

Publit unterstützen.

Publit soll Route und Ticket für Nah- und Fernverkehr in ganz Europa in eine App bringen. Dein Beitrag bezahlt Server, Entwickler-Konten und die Zeit, die das braucht. Keine Werbung, kein Tracking, und Unterstützen schaltet nichts frei: Alle Funktionen bleiben für alle kostenlos.

Monatlich

Am meisten hilft ein kleiner, regelmäßiger Beitrag, weil sich damit planen lässt. Jederzeit kündbar.

Einmalig

Über GitHub Sponsors

Ohne App-Store-Gebühr: Unterstütze Publit direkt auf GitHub – monatlich oder einmalig, mit Kreditkarte oder PayPal. Publit ist Open Source, der ganze Code liegt dort.

♥ Auf GitHub sponsern Code auf GitHub ansehen

So geht's

In der App

Einstellungen → „Publit unterstützen“. Bezahlt wird sicher über den App Store oder Google Play; kündigen kannst du dort jederzeit. Oder ohne App: GitHub Sponsors.

Ohne Geld

Wünsche einreichen und abstimmen, Fehler melden, Publit weitersagen oder deine Stadt zu Transitous bringen. Das hilft genauso.

Wohin das Geld geht

Server für publit.eu, Wunschliste und Live-Daten, die Entwickler-Konten bei Apple und Google und die Entwicklung selbst.

Im App Store öffnen Android-App laden Zu den Wünschen →

Beträge in Euro; im App Store und bei Google Play siehst du den Preis in deiner Währung. Store-Gebühren gehen an Apple bzw. Google – über GitHub Sponsors kommt mehr bei Publit an.

Wohin Publit geht

Eine App für Nah- und Fernverkehr in ganz Europa.

Route finden, Ticket kaufen, einsteigen. Heute plant Publit deine Fahrt und begleitet dich bis zum Aussteigen, der Ticketkauf kommt Schritt für Schritt dazu.
